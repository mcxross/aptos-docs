Kaptos 是一个强大、极具表现力的 Aptos 区块链 Kotlin Multiplatform SDK。它的特性包括基于命名空间的服务 API、受管理的生命周期，以及跨多个平台的完整类型安全。

## 特性

- **类型安全 (Type-safe):** 强类型系统利用 Kotlin 编译器在构建时捕获错误。
- **极具表现力 (Expressive):** 符合习惯的 Kotlin API，使用起来非常直观。
- **多平台 (Multiplatform):** 基于单一代码库即可为 Android、iOS、JVM、JS 和 Native 构建应用。
- **命名空间 API (Namespaced API):** 服务模块（如 `transactions`、`accounts`、`ledger` 等）组织有序，通过统一的 `Aptos` 客户端进行访问。
- **BCS 支持 (BCS Support):** 内置二进制规范序列化（BCS）解析与序列化功能。
- **异步处理 (Asynchronous):** 完全基于 Kotlin Coroutines 构建，实现非阻塞执行。
- **高度可配置 (Configurable):** 可通过 `AptosConfig` 进行深度自定义配置。
- **受管理的生命周期 (Managed Lifecycle):** 自动关闭的托管作用域 (`aptos { }`) 自动负责资源清理。

<Aside type="note">
  Kaptos 目前正在积极开发中。请确保您使用的是最新版本，以获得所有新功能和 API 稳定性。
</Aside>

## 执行交易

Kaptos 提供了一个受管理的生命周期 API，用于简化设置、执行和清理操作。

```kotlin
aptos(AptosConfig(network = Network.DEVNET)) {
  val alice = account()
  faucet.fund(alice.accountAddress, 100_000_000UL)

  val bob = account()
  val payload = TransactionPayload.entryFunctionOf(
    function = "0x1::coin::transfer",
    typeArguments = listOf("0x1::aptos_coin::AptosCoin"),
    bob.accountAddress,
    1_000_000UL,
  )
  val confirmed = transactions.submitAndWait(signer = alice, payload = payload)
}
```
